# GameLingo فارسی — نسخه آزمایشی ۰٫۲

مترجم صفحه بازی اندروید با تم مشکی/بنفش.

## قابلیت‌ها
- حباب شناور قابل جابه‌جایی روی بازی
- گرفتن فریم صفحه با مجوز رسمی MediaProjection اندروید
- تشخیص متن انگلیسی با ML Kit Text Recognition (OCR)
- ترجمه انگلیسی به فارسی با مدل ML Kit
- پردازش OCR روی خود دستگاه؛ تصویر صفحه به سرور ارسال نمی‌شود

## دریافت APK
از بخش Actions مخزن، آخرین اجرای موفق workflow با نام Build Android APK را باز کن و فایل GameLingo-debug-apk را از Artifacts دانلود کن. APK داخل ZIP قرار دارد.

## استفاده
1. برنامه را باز کن و مجوز نمایش روی برنامه‌های دیگر را بده.
2. دوباره دکمه فعال‌سازی را بزن و اجازه ضبط صفحه را تأیید کن.
3. وارد بازی شو و روی حباب بنفش بزن.
4. متن انگلیسی قابل مشاهده شناسایی و ترجمه می‌شود.

## محدودیت‌ها
- اندروید برای هر نشست ضبط صفحه تأیید کاربر می‌خواهد.
- برخی برنامه‌ها/صفحه‌های امن ممکن است ضبط تصویر را مسدود کنند.
- OCR فعلی متن لاتین/انگلیسی را هدف می‌گیرد.
- مدل ترجمه در اولین استفاده دانلود می‌شود؛ پس از آن می‌تواند آفلاین کار کند.
- این نسخه نمونه اولیه است و ممکن است بسته به نسخه اندروید/سازنده گوشی به اصلاح نیاز داشته باشد.
