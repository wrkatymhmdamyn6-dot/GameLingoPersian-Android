# GameLingo فارسی — نسخه آزمایشی ۰٫۱

اپلیکیشن اندروید با تم مشکی/بنفش و پنجره شناور.

## امکانات این نسخه
- صفحه اصلی فارسی و تم اختصاصی
- درخواست مجوز نمایش روی برنامه‌های دیگر
- دکمه شناور قابل جابه‌جایی
- پنل شناور برای واردکردن متن انگلیسی
- ترجمه انگلیسی به فارسی با ML Kit (مدل در اولین استفاده دانلود می‌شود)

## محدودیت مهم
این نسخه هنوز متن را مستقیماً از تصویر بازی استخراج نمی‌کند. برای تجربه کامل ترجمه متن داخل بازی باید قابلیت تصویربرداری امن صفحه (MediaProjection) و OCR اضافه شود. اندروید برای ضبط صفحه تأیید صریح کاربر می‌خواهد.

## ساخت APK در Android Studio
1. Android Studio را نصب کن.
2. این مخزن را با گزینه Open باز کن.
3. اجازه بده Gradle Sync و دریافت وابستگی‌ها کامل شود.
4. از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کن.
5. APK آزمایشی در `app/build/outputs/apk/debug/` ساخته می‌شود.

این پروژه هنوز امضای انتشار (release signing) ندارد؛ خروجی debug برای نصب و آزمایش است.
